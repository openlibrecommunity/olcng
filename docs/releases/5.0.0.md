# oweng 5.0.0

OLCNG is now oweng, based on owenclave.

- Keep the original regular and F-Droid application IDs and signing key for in-place updates
- Import legacy MMKV profiles, subscriptions, selection and compatible settings into Room; retain the original files and a private backup
- Combine 18 built-in subscription sources into one list with configuration-aware deduplication
- Keep last-good source snapshots and a bundled offline list
- Refresh subscriptions at startup, after network changes and after VPN connection
- Add bounded native connection tests, cancellation, batched results and sorting by delay
- Show a short Russian explanation on first launch

Install the matching APK over OLCNG without uninstalling it. Unsupported legacy settings remain in the private migration backup.
