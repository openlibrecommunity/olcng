# oweng 5.0.0

OLCNG теперь oweng на базе owenclave.

- Обновление поверх обычной и F-Droid версии OLCNG с прежней подписью
- Перенос доступных профилей, подписок и совместимых настроек без удаления исходных MMKV-файлов
- Общий список из 18 встроенных подписок с удалением дублей и офлайн-снимком
- Обезличенные имена включены по умолчанию: флаг страны и постоянный номер профиля; исходные имена можно вернуть в настройках
- Встроенный список отображается в Configuration, в Groups остаются пользовательские группы
- Исходная проверка подключений owenclave, 64 работника по умолчанию, сохранение пинга и сортировка
- Список и прокрутка сохраняются при переключении вкладок, в том числе во время проверки

Устанавливайте APK своего варианта и архитектуры поверх OLCNG, не удаляя приложение. При неполном переносе данные остаются в исходном хранилище и частной резервной копии; повторный перенос доступен в настройках.
